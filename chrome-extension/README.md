# AMEX → YNAB Chrome Extension

Import American Express transactions into YNAB directly from your browser. No OTP automation, no servers - just leverage your existing AMEX session.

## Features

- **No OTP/Email Required** - Works with your existing AMEX login
- **Smart Transaction Matching** - Intelligently matches pending → posted transactions
- **Duplicate Prevention** - Automatic deduplication using import IDs
- **Stale Transaction Cleanup** - Removes pending transactions that never posted
- **Real-time Progress** - Live status updates during import

## Quick Start

### 1. Build the Extension

```bash
cd chrome-extension
npm install
npm run build
```

Expected output:
```
dist/background.js     252.6kb
dist/contentScript.js   32.7kb
dist/popup.js           30.7kb
```

### 2. Load in Chrome

1. Open `chrome://extensions/`
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the `chrome-extension` folder

### 3. Get Your Credentials

**YNAB API Key:**
- Go to https://app.youneedabudget.com/settings/developer
- Click "New Token" and copy it

**Budget ID:**
- Open your budget in YNAB
- Copy the ID from URL: `https://app.youneedabudget.com/{budget-id}/...`

**Configure Account Names:**
- Your YNAB account names must match your AMEX card names
- Example: AMEX "Gold Card" → YNAB "Gold"

### 4. Import Transactions

1. Log in to https://global.americanexpress.com/
2. Click the extension icon
3. Enter your YNAB API Key and Budget ID (saved for future use)
4. Click "Start Import"
5. Wait for completion

## How It Works

```
User clicks "Start Import"
    ↓
Background opens AMEX dashboard tab
    ↓
Content script extracts account data from page
    ↓
Content script fetches CSV + pending transactions
    ↓
Background processes transactions:
  - Converts to YNAB format
  - Matches with existing transactions
  - Handles pending → posted transitions
  - Removes duplicates and stale transactions
    ↓
Creates transactions in YNAB
    ↓
Shows success message
```

## Architecture

### Files Structure

```
chrome-extension/
├── src/
│   ├── background.ts      # Service worker, main orchestration
│   ├── contentScript.ts   # Runs on AMEX pages, extracts data
│   ├── popup.ts          # Extension popup UI logic
│   ├── ynab.ts           # YNAB API integration
│   └── types.ts          # TypeScript definitions
├── dist/                 # Built files (generated by npm run build)
├── icons/               # Extension icons
├── manifest.json        # Chrome extension manifest
├── popup.html          # Popup UI
├── package.json        # Dependencies
├── tsconfig.json       # TypeScript config
└── build.js           # Build script
```

### Key Technologies

- **esbuild** - Fast bundler with Node.js polyfills
- **TypeScript** - Type-safe development
- **stream-browserify** - Node.js stream API in browser
- **ynab SDK** - Official YNAB API client
- **csv-parser** - Parse AMEX CSV data

| Feature | Original | Extension |

## Troubleshooting

### "No AMEX accounts found"
- Ensure you're logged in to American Express
- Navigate to https://global.americanexpress.com/dashboard
- Refresh and try again

### "No YNAB account found for [Card Name]"
- YNAB account name must exactly match AMEX card name
- Go to YNAB → Account settings → Rename to match

### "Failed to fetch transactions"
- Check browser console (F12) for errors
- Verify Chrome is up to date
- Try logging out and back in to AMEX

### Build Errors
```bash
# If build fails:
rm -rf node_modules package-lock.json
npm install
npm run build
```

### Transaction Matching Logic

The extension intelligently matches pending transactions when they post:

- **Date matching**: ±3 days tolerance
- **Amount matching**: Exact match or original pending amount
- **Payee matching**: Fuzzy string similarity ≥25%
- **Data preservation**: Copies categories, memos, flags from pending to posted
- **Duplicate prevention**: Uses `import_id` format `YNAB:amount:date:occurrence`

## What Gets Imported

- ✅ Posted transactions (last 10 days)
- ✅ Pending transactions
- ✅ Transaction amounts (converted to YNAB milliunits)
- ✅ Merchant names
- ✅ Transaction dates
- ✅ Account assignments

The extension will:
- Match pending transactions when they post
- Preserve your categories, memos, and flags
- Remove duplicate transactions automatically
- Clean up stale pending transactions

## Security & Privacy

- **Credentials**: Stored in Chrome sync storage (encrypted by Chrome)
- **AMEX Session**: Cookies never extracted, stays in browser
- **API Calls**: Use browser's existing authentication
- **Data Transmission**: No third-party servers
- **Processing**: 100% local in your browser

## Permissions

- `storage` - Save YNAB credentials locally
- `tabs` - Open/focus AMEX tabs
- `activeTab` - Interact with current tab
- `notifications` - Show status notifications
- Host permissions:
  - `https://*.americanexpress.com/*` - Access AMEX pages
  - `https://api.youneedabudget.com/*` - Call YNAB API

## Known Limitations

1. **Manual Login Required**: User must be logged in to AMEX beforehand
2. **Exact Name Matching**: YNAB account names must match AMEX exactly
3. **Date Format**: Uses DD/MM/YYYY (German AMEX format) - may need adjustment for US
4. **No Scheduling**: Must be triggered manually (could add Chrome alarms API)

## Tips

- **Run daily**: Don't run too frequently to avoid rate limiting
- **Review in YNAB**: Check imported transactions after import
- **Pending transactions**: Auto-update when they post
- **Categories preserved**: Your categorization is maintained on pending → posted
